# Mouryan Tech Solution

A modern business website for **Mouryan Tech Solution**, built with React and Vite.

## Features

- Responsive design
- Light/Dark mode
- Service pages
- Contact form
- Professional UI
- Fast performance

## Tech Stack

- React
- Vite
- JavaScript
- CSS/Tailwind CSS (if applicable)

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
